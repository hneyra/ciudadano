# ciudadano

El portal publico de pago de tributos de **Kamayuk**: la cara que ve el contribuyente. Solo
demostracion, sin backend ni login real.

Todo lo que hace falta saber para trabajar aqui —que hay, que no, el stack, las reglas y los
comandos— esta en [`CLAUDE.md`](CLAUDE.md).

```bash
git clone https://github.com/hneyra/kamayuk-lib ../kamayuk-lib   # el clon hermano, en main
cd frontend && yarn install && yarn verificar && yarn dev        # http://localhost:5174/portal/
```
